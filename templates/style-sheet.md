# Style Sheet

`docs/13-self-edit-checklist.md` tells you to keep one of these. This is it.

Fill it in **before** you write chapter 2, not after chapter 20. Every row is a
decision you will otherwise make inconsistently 400 times.

Keep it in the repo. Grep against it. When a collaborator joins, this is the
first file they read.

## Speech

| Decision | This project |
|---|---|
| Quote marks | `"straight"` / `“curly”` / `「corner」` |
| Speech tags | none — the name box does it |
| Attitude clauses after a line | allowed, sparingly |
| Silence line | `"..."` alone, in the speaker's name box |
| Long silence | `"......"` (length scales with weight) |
| Interrupt | `"I—"` em dash, no space |
| Trailing off | `"I don't..."` |
| Stammer | `"I— I mean—"` not `"I-I-I mean"` |

## Punctuation & typography

| Decision | This project |
|---|---|
| Ellipsis | `...` three periods, no spaces, no `…` character |
| Max ellipses per line | 1 |
| Em dash | `—` unspaced |
| Exclamation marks | max 1 per line; none in narration |
| Interrobang `?!` | allowed in dialogue only |
| Emphasis | `*asterisks*` → engine renders italic |
| Numbers | spelled out below 10; digits for times and counts |
| Times | `four-fifteen` in narration, `4:15` on screen |
| SFX text | lowercase italic: `*clack*` |
