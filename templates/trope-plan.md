# Trope Plan

Companion to `docs/16-character-tropes.md` and `docs/17-scene-tropes.md`.

The point of filling this in is not to avoid tropes. It's to **use them
deliberately** — to know which ones you're running, so you can execute them
properly and vary them on purpose rather than by accident.

### Balance check

- [ ] Not more than ~2 major set-pieces per route without a quiet scene between
- [ ] The trope-heavy scenes are spread across the story, not clustered
- [ ] At least one **quiet scene** per route (`docs/11`) — these are the ones
      readers cite as favorites
- [ ] Breather scenes (beach, festival) still carry a turn
- [ ] The seasonal markers, if used, revisit the **same location** across seasons

## Structural tropes in play

| Trope | Used for | Failure mode I'm avoiding | How |
|---|---|---|---|
| | | | |

- [ ] If using amnesia / time loop / rewritten memory: the early scenes are
      **re-readable**, not retconned
- [ ] If using a true-route gate: a player without a guide can find it
- [ ] If using terminal illness: she gets to be angry and bored
- [ ] If using a yandere route: the early scenes read sweet on pass one and
      alarming on pass two, with nothing changed
- [ ] Content warnings written for anything that needs them

## The honest question

For each trope on this page:

> **If a reader has seen this exact scene twenty times before — and they have —
> what is the reason to read mine?**

If the answer is "it's well written," that's acceptable and often enough.
If the answer is nothing, cut the scene or find the angle.
