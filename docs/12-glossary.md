# 12. Glossary

Terms you'll hit in VN communities, dev docs, and reviews.

## Format and presentation

| Term | Meaning |
|---|---|
| **ADV** | Adventure-style layout: text box at the bottom, sprites above. The default. |
| **NVL** | Novel-style layout: text fills most or all of the screen. |
| **Kinetic novel** | A VN with no choices and no branching; purely linear. |
| **Sprite** | A character's standing art, usually with swappable expressions. |
| **CG** | "Computer graphic" — a full-screen illustrated event scene. |
| **Event CG gallery** | The unlockable collection of CGs; a completion incentive. |
| **BG** | Background art. |
| **Backlog / history** | Scrollback of previously shown text. |
| **Skip mode** | Fast-forward; usually "skip read text only" or "skip all". |
| **Auto mode** | Advances text automatically at a set speed. |
| **Textbox / text window** | The container. Sometimes styled per-character. |
| **Name box** | The label showing who's speaking. Replaces prose speech tags. |
| **TIPS / glossary system** | In-game encyclopedia for optional exposition. |
| **Flowchart** | A visual map of the branching structure, jumpable. |

## Structure

| Term | Meaning |
|---|---|
| **Common route** | The shared opening all playthroughs go through. |
| **Route** | A branch dedicated to one character or storyline. |
| **True route / true end** | The canonical resolution, usually gated. |
| **Bad end** | A failure state ending. |
| **Locked route** | A route unavailable until conditions are met. |
| **Flag** | A stored variable recording a player action or story state. |
| **Affection points** | Numeric relationship tracking. |
| **Question arc / answer arc** | *Higurashi*-style structure: mysteries posed, then explained. |
| **Convergent structure** | All routes must be read; each recontextualizes the others. |
| **Gauntlet** | Mostly linear with small local branches. |

## Genre labels

| Term | Meaning |
|---|---|
| **Nakige** | "Crying game" — comedy-heavy build to an emotional/tragic payoff. |
| **Utsuge** | "Depressing game" — bleak throughout, no rescue promised. |
| **Chuunige** | Bombastic supernatural action with grandiose rhetoric. |
| **Nukige** | Primarily erotic content; thin plot by design. |
| **Eroge** | Adult VN broadly (many have substantial narratives). |
| **Otome game** | Romance VN aimed at a female audience, usually multiple male love interests. |
| **BL / GL** | Boys' love / girls' love romance. |
| **Nichijou-kei** | Everyday/slice-of-life register. |
| **Denpa** | Disorienting, paranoid, reality-unstable psychological work. |
| **Doujin** | Independent/self-published. |

## Character archetypes (shorthand, not destinations)

Quick definitions only. For why each works, its failure mode, and how to make it
load-bearing, see `docs/16-character-tropes.md`.

| Term | Meaning |
|---|---|
| **Tsundere** | Hostile exterior concealing affection. |
| **Kuudere** | Cool, flat-affect exterior; warmth is rare and meaningful. |
| **Dandere** | Shy and quiet; opens up slowly. |
| **Yandere** | Affection that turns possessive/violent. |
| **Genki** | High-energy, loud, relentlessly upbeat. |
| **Ojou-sama** | Wealthy, refined, often haughty. |
| **Onee-san** | Older-sister figure; teasing, confident, protective. |
| **Imouto** | Younger-sister figure or character type. |
| **Senpai / kouhai** | Senior / junior in a school or workplace hierarchy. |
| **Osananajimi** | Childhood friend. |
| **Boke / tsukkomi** | Comic fool / straight man. The core comedy duo structure. |

## Craft terms used in this repo

| Term | Meaning |
|---|---|
| **Box** | One screen of text, terminated by a click. The unit of composition. |
| **Beat** | A pause or a small unit of dramatic action. |
| **Turn** | The moment in a scene where something changes. |
| **Button** | The closing 1–3 boxes that land a scene. |
| **Withholding break** | Ending a box mid-sentence to charge the next click. |
| **Filter word** | *saw, heard, felt, realized* — perception verbs that add distance. |
| **Fingerprint** | The set of traits that make a character's dialogue identifiable. |
| **Grounding beat** | A physical/sensory box dropped into long dialogue. |
| **Echo** | Narration that restates what dialogue just said. Cut it. |
| **Gap** | Narration that contradicts or complicates dialogue. Keep it. |

## Production

| Term | Meaning |
|---|---|
| **Ren'Py** | The dominant open-source VN engine (Python-based). |
| **TyranoBuilder / Naninovel / Monogatari** | Other common engines. |
| **KiriKiri / NScripter** | Older Japanese engines; many classics run on these. |
| **Script** | The written text plus engine directives. |
| **Line count / box count** | Scale measure; often more useful than word count. |
| **Voice acting (CV)** | "Character voice"; often partial (heroines only, protagonist unvoiced). |
| **Localization** | Translation plus cultural adaptation. |
