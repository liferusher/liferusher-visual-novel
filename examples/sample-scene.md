# Sample Scene, Annotated

One complete scene written to the rules in this repo, with margin notes.

**Setup:** Rei (protagonist, first person present) needs a form signed by Kaede,
the club president. They had an argument last week that neither has mentioned.
This is roughly 45 boxes — a short-to-medium VN scene.

Notation: `>` = click / box break. `[ ]` = engine direction.

---

## What the scene does, checked against the repo

| Check | Where |
|---|---|
| **Anchor** | Box 1–2, clubroom + time + light |
| **Hook** | Kaede's back is turned and she's not acknowledging him |
| **Goal** | Surface: get a signature. Real: find out if they're okay. |
| **Obstacle** | She won't turn around |
| **Turn** | She turns around, visibly crying, and is angry about it |
| **Button** | "No." + the light changing |
| **Grounding beats** | The clock; the chair scrape; the sunset |
| **Withholding break** | "That was a mistake." → click → she turns |
| **Silence lines** | Two `"..."` boxes, both load-bearing |
| **Speech tags** | Zero |
| **Adverbs on speech** | Zero |
| **Narration echoing dialogue** | Zero |
| **Emotion words** | One ("furious"), placed at the turn for impact |
| **Sprite redundancy** | Narration adds *why* she's angry, which the sprite can't |
| **Box length variation** | 1 line → 4 lines → 1 line → 1 word |
| **Engine used for effect** | BGM cut before the button; BG change on the last box |

## What was deliberately NOT done

- **No explanation of last week's argument.** The reader doesn't need it yet, and
  withholding it makes them want the next scene.
- **No resolution.** The turn is emotional, not plot. They're not okay; they're
  now *visibly* not okay, which is progress.
- **No description of Kaede's appearance.** Sprite's job.
- **No "I realized she was crying."** Filter word. Just: she's been crying.
- **No wind-down after the button.** The scene stops on the image.

## Exercise

Rewrite this scene three ways:

1. **As comedy** — same beats, Kaede never cries, the form gag escalates to
   absurdity. Where does the turn go?
2. **As horror** — same room, same withholding structure, but what she's facing
   away from is the window. Change nothing about the *pacing*, only the content.
3. **From Kaede's POV** — she's been sitting there for an hour. What does she
   know that Rei doesn't?

Doing all three teaches more about VN wording than reading another chapter of
theory.
